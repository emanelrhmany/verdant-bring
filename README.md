# Verdant — Responsive Plant Shop

A modern indoor plant shop landing page made with **HTML5 and CSS3 only**.

## Included
- Hero section
- Plant category cards
- Bestseller product cards with hover states
- Plant-care banner
- Benefits section and footer
- Responsive layouts for desktop, tablet, mobile, and small phones

## Run
Open `index.html` in a browser. Images and Google Fonts are loaded online, so an internet connection is needed for those assets.

## Important
This is a static front-end project. Product links are demo navigation only; no cart or checkout functionality is included.
